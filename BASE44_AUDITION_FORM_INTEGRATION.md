# Retired: Base44 audition form integration

The KC Forma/Base44 form is no longer the active audition application flow.

The live application is now native to the Kinetic Crew website:
- \`/audition-application.html\` submits directly to Supabase.
- \`/track-application.html?token=...\` provides private application tracking.
- Admin and Super Admin review applications in \`/audition-admin.html\`.

See \`AUDITION_PORTAL_DEPLOYMENT_NOTES.md\` for the active workflow and email behaviour.
